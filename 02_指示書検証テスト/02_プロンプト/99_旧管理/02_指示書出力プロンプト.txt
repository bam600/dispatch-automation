02_指示書出力プロンプト

【目的】

「01_指示書読込プロンプト」で抽出・判定された読込結果を使用し、
添付された配車指示書Excelテンプレートの適切な項目へ入力してください。

最終成果物は、既存テンプレートのレイアウトを可能な限り維持した
PDFファイル(.PDF)にしてください。


【前提】

- このプロンプトは「01_指示書読込プロンプト」の出力結果を受け取った後に使用します。
- 原則として、読込結果に記載された情報だけを使用してください。
- 原本画像や過去案件、一般知識から新たな情報を推測・補完しないでください。
- ケースIDが指定されている場合は、そのケースIDを維持してください。
- 出力ファイル名は、指定がない場合「DXXX_出力結果.xlsx」の形式にしてください。


【最重要ルール】

1. 読込結果に「明確に確認できた情報」として記載された内容のみ確定入力してください。

2. 「要確認」とされた情報は、確定値としてExcelへ入力しないでください。
   入力先候補が分かる場合でも、値そのものは確定しないでください。

3. 「記載なし」とされた情報は空欄のままにしてください。

4. 「矛盾している情報」は、どちらか一方を勝手に採用しないでください。
   必ず要確認として扱ってください。

5. 「朝一」「午後一」「午前中」「○時頃」「○時まで」「○時以降」などの表現は、
   勝手に具体的な時刻へ変更せず、読込結果の表現をそのまま保持してください。

6. 複数の積地・卸地がある場合は、読込結果に示された順番を必ず保持してください。

7. テンプレートの項目名と読込結果の項目名が完全一致しなくても、
   意味が明確に一致する場合のみ入力してください。

8. 入力先が複数考えられる場合や、判断に迷う場合は、
   勝手に配置せず「要確認」としてください。

9. 既存テンプレートの以下を可能な限り変更しないでください。
   - 罫線
   - セル結合
   - 列幅
   - 行高
   - 色
   - フォント
   - 数式
   - 印刷設定
   - ページ設定
   - 既存のレイアウト

10. 既存セルに値が入っている場合は、勝手に上書きしないでください。
    読込結果と既存値が異なる場合は要確認としてください。

11. 車種情報は入力漏れを防ぐため、独立して確認してください。
    読込結果に「車種」という独立項目がある場合は、その値を車種情報として使用してください。
    独立項目がなくても、「荷物の詳細」「その他の抽出情報」等の読込結果内に
    車種を明確に示す記載が含まれている場合は、その部分を車種情報として扱ってください。
    ただし、原本画像を再確認して新たに車種を推測・補完してはいけません。

12. 読込結果で車種が明確に確認でき、かつテンプレートに「車種」欄が明確に存在する場合は、
    車種欄への入力を必須としてください。
    この条件を満たすのに車種が未入力の場合は「入力漏れ」とし、
    生成結果を「成功」にせず「要確認」としてください。


【絶対に配車指示書へ入力してはいけない情報】

以下は、読込結果に存在していても、
傭車先・運送会社向けの配車指示書Excelには絶対に転記しないでください。

- 荷主会社名
- 荷主住所
- 荷主FAX番号
- 荷主側の担当者情報
- 運賃
- 売上
- 仕入金額
- 支払金額
- 単価
- その他すべての料金・金額情報

金額情報については、表示可否を判断せず、すべて出力対象外としてください。


【荷主情報と積地・卸地情報の区別】

以下は入力対象です。

- 積地として必要な会社名・施設名
- 積地住所
- 積地担当者
- 積地電話番号
- 卸地として必要な会社名・施設名
- 卸地住所
- 卸地担当者
- 卸地電話番号

ただし、同じ会社名が荷主情報としても記載されている場合があります。

「荷主情報」なのか「積地・卸地の現場情報」なのかを混同しないでください。
役割が明確でない場合は要確認としてください。


【入力先対応表】

4. 積日
→ テンプレート内の「積日」「積込日」「積込年月日」など、
  明確に積込日を示す欄へ入力してください。

5. 積時間
→ 「積時間」「積込時間」「積込時刻」などへ入力してください。
→ 「頃」「まで」「以降」「朝一」等の条件語は必ず保持してください。

6. 積地住所
→ 「積地住所」「積込先住所」などへ入力してください。

7. 積地建物名称
→ 「積地名」「積地会社名」「積込先名」「施設名」など、
  意味が明確に対応する欄へ入力してください。
→ 専用欄がなく、テンプレート上「その他」が現場名を記載する運用になっている場合のみ、
  「その他」欄を入力先候補としてください。
→ 判断できない場合は要確認としてください。

8. 積地担当者
→ 「積地担当者」「積込先担当者」「現地担当者」などへ入力してください。

9. 積地電話番号
→ 「積地TEL」「積地電話番号」「積込先TEL」などへ入力してください。

10. 卸日
→ 「卸日」「納品日」「荷卸日」などへ入力してください。

11. 卸時間
→ 「卸時間」「納品時間」「荷卸時間」などへ入力してください。
→ 「頃」「まで」「以降」「朝一」等の条件語は必ず保持してください。

12. 卸地住所
→ 「卸地住所」「納品先住所」「荷卸先住所」などへ入力してください。

13. 卸地建物名称
→ 「卸地名」「卸地会社名」「納品先名」「施設名」など、
  意味が明確に対応する欄へ入力してください。
→ 専用欄がなく、テンプレート上「その他」が現場名を記載する運用になっている場合のみ、
  「その他」欄を入力先候補としてください。
→ 判断できない場合は要確認としてください。

14. 卸地担当者
→ 「卸地担当者」「納品先担当者」「現地担当者」などへ入力してください。

15. 卸地電話番号
→ 「卸地TEL」「卸地電話番号」「納品先TEL」などへ入力してください。

17. 荷物内容
→ 「品名」「荷物内容」「商品名」など、
  意味が明確に一致する欄へ入力してください。

18. 荷物の詳細
→ 読込結果に数量・荷姿・重量・車種・台数などが含まれている場合、
  テンプレートに対応する専用欄が明確に存在するときだけ分けて入力してください。
→ どの内容をどの欄へ入れるか判断できない場合は、勝手に分割しないでください。
→ 専用欄がなく「その他」「備考」等への入力が適切か明確な場合のみ入力してください。
→ 判断に迷う場合は要確認としてください。

【車種情報の取扱い（追加）】

→ 読込結果に車種が独立項目として存在する場合は、その値を最優先で使用してください。
→ 独立項目がない場合でも、「荷物の詳細」等の読込結果内に
  「4tウイング」「2t平」など、車種を明確に示す情報が含まれている場合は、
  その部分を車種として切り分けて扱ってください。
→ テンプレートに「車種」欄が存在する場合は、その欄へ入力してください。
→ 車種を「積荷」「積荷内容」「装備品」「その他」へ代替入力しないでください。
→ 車種と数量・荷姿・重量・台数が同一項目に含まれている場合は、
  車種だけを車種欄へ入力し、残りは対応する専用欄が明確な場合のみ入力してください。
→ 読込結果に車種情報が存在しない場合は、原本画像や一般知識から補完しないでください。
→ 読込結果に明確な車種情報があり、テンプレートにも車種欄があるのに未入力となった場合は、
  「入力漏れ」として要確認にしてください。

19. 装備品
→ 「装備」「必要装備」「車両装備」「積込装備」などへ入力してください。

20. 注意事項
→ 「注意事項」「備考」「その他」など、
  内容の用途が明確に一致する欄へ入力してください。

21. 積地・卸地の順番
→ Excel上で複数地点を配置する順番を決めるために使用してください。
→ 例：
  積地① → 積地② → 卸地① → 卸地②
→ 順番そのものを、不要なセルへ文字列として入力しないでください。


【入力禁止項目】

読込結果の以下の番号はExcelへ転記しないでください。

1. 荷主会社名
2. 荷主住所
3. 荷主FAX番号
16. 運賃

また、番号に関係なく金額情報が含まれている場合はすべて入力禁止です。


【複数積地・複数卸地のルール】

- 原本・読込結果の順番を維持してください。
- 日付、時間、住所、建物名、担当者、電話番号の紐付けを崩さないでください。
- 積地①の時間を積地②へ入れるなど、地点間で情報を移動しないでください。
- テンプレートに入力欄が足りない場合は、勝手に省略せず要確認としてください。
- テンプレートのレイアウトを大きく変更して欄を増設しないでください。


【過去案件・流用データの扱い】

- 過去案件の情報は、今回の読込結果を補完する確定値として使用しないでください。
- 過去案件と今回の情報が異なる場合は、今回の読込結果を優先してください。
- 過去案件の担当者、住所、時間等を自動で今回へ上書きしないでください。
- 過去情報を使用する必要がある場合は「候補」として扱い、人の確認を必要としてください。



【Excel書込・PDF出力時間の記録ルール】

- 「Excel書込開始時刻」は、読込結果をExcelテンプレートへ反映するため、
  最初のセルへの書き込み・変更を開始する直前の現在時刻としてください。
- Excelテンプレートの確認だけを行っている時間は、
  「Excel書込開始時刻」より前として扱ってください。
- 「PDF出力完了時刻」は、Excelへの必要な入力・確認・保存を終え、
  PDFファイルの生成が完了し、出力ファイルが存在することを確認した時点の現在時刻としてください。
- 「Excel書込・PDF出力所要時間」は、
  「Excel書込開始時刻」から「PDF出力完了時刻」までの差を計算してください。
- 所要時間は「○分○秒」で表示し、あわせて総秒数も記録してください。
- 時刻は日本時間（JST）で「YYYY/MM/DD HH:MM:SS」の形式にしてください。
- 時刻や所要時間を推測で作成しないでください。
- 正確な時刻を取得できない場合は、その項目を「時刻取得不可」としてください。
- 「01_指示書読込プロンプト」の画像読込・抽出時間とは別の処理時間として記録してください。
- 「処理完了時刻」「画像読込完了時刻」など、別工程の時刻を代用しないでください。

【処理手順】

1. 読込結果のケースIDを確認する。

2. 添付されたExcelテンプレートの項目名とレイアウトを確認する。

3. 読込結果の各項目について、
   「そのまま使用できる情報」
   「要確認」
   「記載なし」
   「矛盾」
   を区別する。

4. 入力禁止情報を除外する。

5. 「そのまま使用できる情報」のうち、
   テンプレート内の入力先が明確に特定できる項目だけを入力する。

6. 複数積地・卸地の場合は順番と情報の紐付けを再確認する。

7. 既存テンプレートの書式・数式・印刷設定を維持する。

8. 入力後、禁止情報が混入していないか再確認する。

9. 入力後、読込結果とExcelの内容を照合し、
   入力漏れ、別欄への誤入力、順序逆転がないか確認する。

10. 編集可能なExcel形式（.xlsx）で保存する。

11. 配車指示書をPDF形式で出力する。

12. PDFファイルの生成完了とファイル存在を確認した直後に、
    「PDF出力完了時刻」を記録する。

13. 「Excel書込開始時刻」から「PDF出力完了時刻」までを計算し、
    「Excel書込・PDF出力所要時間」として記録する。


【出力前の禁止情報チェック】

Excelを保存する前に、以下を必ず確認してください。

■荷主会社名
- 出力されていないこと

■荷主住所
- 出力されていないこと

■荷主FAX番号
- 出力されていないこと

■荷主側担当者情報
- 出力されていないこと

■運賃
- 出力されていないこと

■売上・仕入・支払・単価・その他金額
- 出力されていないこと

1件でも含まれている場合は、保存前に削除してください。


【出力後の確認】

以下を確認してください。

- 明確な情報の入力漏れがないか
- 読込結果に明確な車種情報があり、テンプレートに車種欄がある場合、その車種が正しく入力されているか
- 車種が積荷・積荷内容・装備品・その他など別の欄へ誤入力されていないか
- 「要確認」の情報を確定入力していないか
- 「記載なし」の項目を勝手に補完していないか
- 矛盾情報のどちらかを勝手に採用していないか
- 積地・卸地の順番が変わっていないか
- 日付・時間が別地点へ誤って紐付いていないか
- 「頃」「まで」「以降」「朝一」等が削除されていないか
- 禁止情報が出力されていないか
- テンプレートの書式・数式・印刷設定が壊れていないか


【処理後の報告形式】

■生成ファイル
- ファイル名：

■自動入力した項目
- 項目名 → 入力先
- 項目名 → 入力先

■入力しなかった項目
- 項目名：理由

■要確認の項目
- 項目名：理由

■複数地点チェック
- 順番保持：問題なし／要確認
- 日時との紐付け：問題なし／要確認

■禁止情報チェック
- 荷主会社名：出力なし／要確認
- 荷主住所：出力なし／要確認
- 荷主FAX番号：出力なし／要確認
- 荷主側担当者情報：出力なし／要確認
- 運賃・その他金額情報：出力なし／要確認

■テンプレート確認
- レイアウト：維持／要確認
- 数式：維持／要確認
- 印刷設定：維持／要確認

■Excel書込・PDF出力時間
- Excel書込開始時刻：YYYY/MM/DD HH:MM:SS
- PDF出力完了時刻：YYYY/MM/DD HH:MM:SS
- Excel書込・PDF出力所要時間：○分○秒（総秒数：○秒）

■生成結果
- 成功／要確認
- 読込結果に明確な車種情報があり、テンプレートに車種欄が存在するにもかかわらず
  車種が未入力の場合は「成功」とせず「要確認」としてください。

■人による最終確認が必要な項目数
- ○件


【最終ルール】

- 分からない情報を埋めることより、誤った情報を確定しないことを優先してください。
- 入力できない項目があっても、推測して完成させないでください。
- 禁止情報の誤出力は0件としてください。
- 最終的な送付前確認は人が行う前提としてください。
